# Howler

A decibel meter. Android first (Kotlin + [Oboe](https://github.com/google/oboe)), iOS later.

First real dogfood project for the [Tessera](../tessera) framework — see `CLAUDE.md` for how
this repo is worked and `docs/SCAFFOLD-NOTES.md` for the framework friction the scaffold surfaced.

## Status

Scaffolded harness (Tessera layer) only. App skeleton pending an Android toolchain — see
`docs/SCAFFOLD-NOTES.md`.
